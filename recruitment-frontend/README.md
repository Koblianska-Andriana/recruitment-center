# Recruitment Center — Frontend прототип

## Запуск
1. Встановити Node.js (LTS).
2. Відкрити цю папку у VS Code.
3. Виконати `npm install`.
4. Виконати `npm run dev`.
5. Відкрити адресу, яку покаже Vite (зазвичай http://localhost:5173).

## Що вже є
- Головна сторінка з показниками структури.
- Сторінка рекрутингових центрів: 10 записів із SQL INSERT, пошук, таблиця.
- Перемикач між демо-режимом і запитом `GET /api/recruitment_centers`.
- Сторінки-заготовки «Рекрути», «Навчальні курси», «Інструктори».
- Перелік 15 запитів з методички без вигаданих результатів.

## Як під'єднати сервер
Створити файл `.env` у корені (на основі `.env.example`) і вказати `VITE_API_URL=https://...` (без кінцевого `/`). Перезапустити `npm run dev`. У розділі «Рекрутингові центри» ввімкнути «Дані з API». Якщо сервер не працює, побачите помилку, а не фальшиві дані. Сервер повинен дозволяти CORS для адреси фронтенду.

## Що ще потрібно від команди
- Підтвердження робочої адреси API та тестування `GET /api/recruitment_centers`.
- Маршрути і приклади JSON для рекрутів, курсів, інструкторів.
- API-контракт для 15 SQL-запитів.
- Узгодження форм створення/редагування, якщо вони потрібні за ролями.

Це прототип фронтенду, а не завершена інтегрована система. Структура таблиць взята з наданої ER-діаграми, дані центрів — з наданого SQL. Інші записи не вигадані.
